## 一句话介绍

**【个性化智能学习硬件】是一台为 3–12 岁孩子打造的 AI 语音伙伴**——喊一声「你好小智」就能聊天，能教孩子写汉字、学成语、练英语，还会记住每个孩子的喜好和学习进度，越用越懂他。家长在手机/电脑后台就能配置内容、布置生字、打印田字格。

## 核心能力（孩子能玩到什么）

### 1. 语音陪伴：喊一声就能聊

- 离线唤醒词「**你好小智**」，不用按键、不用解锁，孩子自己就能用。
- 端到端响应**约 2 秒**，说完一句很快就有回应，像真的在对话。
- 儿童友好音色，会讲故事、答科普、陪做口算。

[视频：唤醒 →「给我讲个恐龙的故事」→ 流畅回答]

### 2. 汉字描红：跟着一笔一画写

- 孩子说「**『象』字怎么写**」「大象的象」，屏幕立刻进入**田字格**，用**正楷**一笔一画**逐笔显影**演示写法。
- 写完后**点一次重播**、**点两次退出**，反复看不腻。
- 家长可在后台**批量布置生字**并下发到设备。

[图片：田字格描红「象」字逐笔过程]
[视频：语音触发描红 → 逐笔书写 → 点击重播/退出]

### 3. 成语学习：大字 + 解读 + 故事

- 孩子问「**夜郎自大是什么意思**」，屏幕用 **2×2 大字**显示成语，并**朗读「解读 + 典故故事」**。
- 说「**讲个成语**」，会从已录入的成语库里随机讲一个。
- 库里没有的四字成语会**自动生成并入库**，越用越丰富。

[图片：2×2 大字成语界面「夜郎自大」]
[视频：问成语含义 → 大字展示 + 朗读解读与故事]

### 4. 英语学习场景：进出有提示，像换了个老师

- 孩子说「**我想学英语**」，会响起固定提示音「Yay! Let's practice English together! 我们开始英语练习啦～」并切换到**少儿英语老师人设**（英文为主、中文搭桥、多鼓励）。
- 进入英语场景时屏幕会切换到「经典脸」陪练形象。
- 说「**换回中文**」就退出，回到日常聊天。
- 针对常见单词做了**识别优化**，孩子说「Hello」「Banana」也能听准。

[视频：「我想学英语」进场景 → 英文对话 → 「换回中文」退出]

### 5. 会成长的记忆：越用越懂孩子

- 记住孩子的**名字、喜好、学习特征**，并随对话不断更新画像。
- **多轮上下文**让对话连贯，不会「聊一句忘一句」。
- 家长可在后台**查看 / 修改 / 删除**记忆，完全可控。

### 6. 会表情的彩虹蝴蝶界面

- 主界面是**不断变换鲜艳色彩、翅膀煽动**的彩虹蝴蝶，跟随语音状态表达「专注 / 好奇 / 思考 / 说话 / 开心」等表情。
- 也保留经典「卡通脸」界面，**家长可在设置里一键切换**。

## 快速上手（拿到设备这样做）

> 整个过程约 5 分钟。

### 第 1 步：开机

- 长按电源 / 插上充电，屏幕亮起彩虹蝴蝶即为开机成功。
- 板载锂电池支持**连续对话 2 小时以上**。

[图片：开机点亮屏幕]

### 第 2 步：连 Wi-Fi（配网）

- 首次使用需联网。按设备提示进入配网，把设备连入家里的 Wi-Fi。
- 联网成功后屏幕显示「**在线**」，即可开始对话。

[图片：配网界面 / 在线状态]
[视频：配网全过程]

> 提示：建议连 **2.4GHz** 家用 Wi-Fi、信号尽量强，避免离路由器太远导致断连。

### 第 3 步：开始对话

- 喊「**你好小智**」唤醒，听到回应后直接说你的需求即可。
- 试试这些：
  - 「给我讲个故事」
  - 「3 加 5 等于几」
  - 「『水』字怎么写」
  - 「守株待兔是什么意思」
  - 「我想学英语」

## 家长控制台（后台怎么用）

家长在电脑/手机浏览器打开控制台，即可管理内容和查看孩子的使用情况。

> 控制台地址与登录方式请按随附说明卡获取。

[图片：控制台首页总览]

### 生字管理：布置 + 打印

- **批量录入**要教的汉字，一键**下发到设备**让孩子描红。
- 一键生成 **A4 田字格练习页**（带正楷字形 + 组词），手机长按保存、电脑下载，**打印出来给孩子练字**。

[图片：生字管理页 + A4 打印预览]

### 成语学习：建库 + 下发

- 批量录入成语，按分组管理；可**生成 / 编辑 / 试听**「解读 + 故事」，再下发给设备朗读。

### 场景配置：自定义老师人设

- 在「**场景**」页可编辑英语等学习场景的**触发词、老师人设、进出提示音**，也能恢复默认。
- 默认对话的**基础人设**与**孩子画像（Bot 画像）**也在这里统一设置。

[图片：场景配置页]

### 记忆管理：看得见、改得动

- 查看孩子的对话记忆与用户画像，可**单条修改 / 删除**（删除前有确认），数据完全由家长掌控。

### 模型与用量

- 可配置对话所用的大模型 Key，并按场景查看 **Token 用量统计**，花费心里有数。

## 常见问题（FAQ）

**Q：必须联网吗？**
A：唤醒词「你好小智」是离线识别，不联网也能唤醒；但对话、描红、成语、英语等能力需要联网才能使用。

**Q：内容安全吗？会乱答吗？**
A：内置内容安全护栏，只回答学习、科普、故事、口算类问题，主动拒绝不良内容。

**Q：一次能用多久？**
A：板载锂电池支持连续对话 2 小时以上，充电后可继续使用。

**Q：「在线」一直连不上 / 偶尔掉线怎么办？**
A：优先靠近路由器、使用 2.4GHz 强信号 Wi-Fi；设备具备断线自动重连能力，网络恢复后会自动连回。

**Q：说完话要等一下才有反应？**
A：首次唤醒联网建链会稍慢属正常，之后会快很多；如果持续偏慢，多为网络环境问题，建议更换更强的 Wi-Fi。

**Q：一台设备能给两个孩子用吗？**
A：可以，记忆按孩子（用户）维度区分，家长也可在后台分别管理。
